CARREIRA DO NELO DEV — PORTFÓLIO HTML/CSS

Conteúdo:
- index.html: página principal do portfólio
- style.css: estilos, responsividade e animações
- sistemas/: sete demonstrações independentes, cada uma com index.html e style.css

COMO VER NO COMPUTADOR
1. Extraia o ZIP.
2. Abra index.html no navegador.
3. Clique em “Ver demonstração” em qualquer sistema.

COMO PUBLICAR NA INTERNET
1. Entre em https://app.netlify.com/ e crie sessão.
2. Escolha a opção de adicionar/publicar um site manualmente (Deploy manually).
3. Arraste a pasta extraída completa, contendo index.html, style.css e a pasta sistemas.
4. O Netlify vai gerar um endereço público. Teste o endereço e cada um dos sete links.

NOTAS IMPORTANTES
- Os sete projetos são protótipos de demonstração com dados fictícios.
- A base do projeto é HTML e CSS. Algumas demonstrações incluem pequenas interações em JavaScript inline, por exemplo validação demonstrativa e adição de tarefas; não existe backend nem base de dados.
- Os formulários não enviam dados para um servidor. Não introduza dados pessoais reais.
